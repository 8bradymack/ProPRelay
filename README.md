# ProP Relay

ProP Relay runs on the Mac with ProPresenter. It receives drawings from the ProP Control app on an
iPad or iPhone and sends them out as an NDI source you can layer over your slides.

## [Download ProP Relay 1.0 (74)](https://github.com/8bradymack/ProPRelay/releases/latest/download/ProPRelay.zip)

For macOS 14 or later. What changed in each version: [Releases](https://github.com/8bradymack/ProPRelay/releases).
Earlier versions are in [Older Versions](Older%20Versions).

## Install

1. Open the downloaded zip and drag **ProPRelay** into your **Applications** folder.
2. Open it from Applications. macOS says it can't verify the app: click **Done**.
3. Open **System Settings > Privacy & Security**, scroll down, and click **Open Anyway** next to
   ProPRelay. Confirm with your Mac password. You only do this once.
4. When asked, allow **Local Network** access so devices can find the Mac.

ProP Relay lives in the menu bar. Set its name and password, and whether it opens at login, in
**Settings**.

## Updates

ProP Relay checks this page for new versions. When one is out, the menu shows **Update Available**,
and between services (no device connected for a few minutes) a window offers to install it. You
can also check in **Settings > Updates**. Updates install with one click: no need to download
again or approve anything.
